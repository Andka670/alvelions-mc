Cara join

Empat langkah dari instalasi sampai punya base sendiri.

  1. Tambah server

    Tekan tombol di atas, atau tambahkan manual: alvelionssmp.my.id port 26714.

  2. Ambil hadiah awal

    Di lobby: NPC Starter Kit, Daily Reward, dan Redeem Code dengan kode ALVELIONS.

  3. Mulai membangun

    Ketik /rtp untuk teleport ke luar zona aman, lalu dirikan basemu.

  4. Cari money

    Bertani, ikut quest, jual hasil ke /shop atau merchant, atau buka jasa untuk pemain lain.
